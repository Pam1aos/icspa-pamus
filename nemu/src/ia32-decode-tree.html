IA-32 指令解码决策树

逐字节解析流程 — 从机器码到汇编指令

🔍 逐字节解析实例（六大分支各选一条）

例1: 双操作数, 两个寄存器 (mod=11)

机器码: 03 C3 → AT&T: addl %eax, %ebx

字节0
03 = opcode → opcode_entry[0x03] = add_rm2r_v (Intel: ADD Gv,Ev → AT&T: addl src, %reg)
字节1
C3 = ModR/M = 11 000 011
  mod=11 → case_mod_11: 两个操作数都是寄存器
  reg=000 → opr_dest = REG_EAX (目标寄存器)
  r/m=011 → opr_src = REG_EBX (源操作数)
长度
len = 1(opcode) + 1(ModR/M) = 2 字节
执行
operand_read(EBX) → opr_src.val = cpu.ebx
alu_add(opr_src.val, opr_dest.val, 32) → cpu.ebx += cpu.eax, 设标志位
operand_write(EAX) → cpu.eax 更新
cpu.eip += 2

例2: 双操作数, 内存+寄存器 (mod=10, SIB, disp32)

机器码: 89 94 83 00 11 00 00 → AT&T: movl %edx, 0x1100(%ebx,%eax,4)

字节0
89 = opcode → opcode_entry[0x89] = mov_r2rm_v (Intel: MOV Ev,Gv → AT&T: movl %reg, %rm)
字节1
94 = ModR/M = 10 010 100
  mod=10 → case_mod_10: 内存, +disp32
  reg=010 → opr_src = REG_EDX (源=寄存器)
  r/m=4 → 触发 SIB 解析！
字节2
83 = SIB = 10 000 011
  ss=10 → scale = ×4
  index=000 → idx = cpu.eax × 4
  base=011 → opr_dest.base = REG_EBX
字节3~6
00 11 00 00 = disp32 (小端) = 0x00001100
opr_dest.addr = cpu.ebx + cpu.eax×4 + 0x1100
opr_dest.sreg = SREG_DS (rm=EBX, 非 EBP)
opr_dest.type = OPR_MEM
长度
len = 1 + 1(ModR/M) + 1(SIB) + 4(disp32) = 7 字节
执行
operand_read(EDX) → 读 EDX 的值
operand_write(内存[EBX+EAX×4+0x1100]) → 写入内存
cpu.eip += 7

例3: 单字节, 无 ModR/M (寄存器编码在 opcode 里)

机器码: 50 → AT&T: pushl %eax

字节0
50 = opcode → opcode_entry[0x50] = push_r_v
reg = opcode & 7 = 0 = REG_EAX
decode_operand_r: opr_src = {OPR_REG, addr=EAX}
无 ModR/M！寄存器号直接嵌在 opcode 低 3 位里
长度
len = 1 字节
执行
operand_read(EAX) → val = cpu.eax
cpu.esp -= 4
vaddr_write(cpu.esp, SREG_SS, 4, cpu.eax)
cpu.eip += 1

例4: 无 ModR/M, 有 4 字节偏移 (直接 CALL)

机器码: E8 00 01 00 00 → AT&T: call 0x30105 (假设 eip=0x30000)

字节0
E8 = opcode → opcode_entry[0xE8] = call_rel32
指令长度固定 = 5 字节 (opcode + 4B偏移)
无 ModR/M, 无 SIB — 操作数全是隐式的
字节1~4
00 01 00 00 = rel32 (小端) = 0x00000100 = +256
是有符号数: 正数 = 往前跳, 负数 = 往后跳
执行
rel32 = instr_fetch(eip+1, 4) = 0x100
len = 5
① cpu.esp -= 4
② vaddr_write(cpu.esp, SS, 4, eip+5=0x30005) ← 存返回地址
③ cpu.eip += 0x100 = 0x30100 ← 跳转目标
注意: 返回地址是 eip+5 (下一条指令), 不是 eip 本身

例5: 两字节 opcode (0x0F)

机器码: 0F 44 C1 → AT&T: cmove %ecx, %eax

字节0
0F = 两字节 opcode 前缀 → opcode_entry[0x0F] = opcode_2_byte()
读第 2 字节 op2 = instr_fetch(eip+1, 1) = 0x44
字节1
44 = op2 → opcode_2_byte_entry[0x44] = cmove_rm2r_v
条件码: condition_e (ZF=1 则执行传送)
字节2
C1 = ModR/M = 11 000 001
  mod=11 → 纯寄存器
  reg=000 → opr_dest = REG_EAX (条件成立时写入)
  r/m=001 → opr_src = REG_ECX (来源)
长度
len = 1(前缀0F) + 1(op2) + 1(ModR/M) = 3 字节
执行
if (cpu.eflags.ZF == 1): operand_read(ECX) → EAX = ECX
else: 什么也不做
cpu.eip += 3

例6: Group 指令 (需读 ModR/M.reg 决定子操作)

机器码: 83 00 05 → AT&T: addl $5, (%eax)

字节0
83 = opcode → opcode_entry[0x83] = group_1_bv()
需要再读 ModR/M → reg 字段决定是 ADD/OR/ADC/...
字节1
00 = ModR/M = 00 000 000
  mod=00 → case_mod_00: 内存 [EAX]
  reg=000 → 子操作码 = 0 = ADD
    → group_1_bv_entry[0] = add_i2rm_bv
  r/m=000 → opr_dest = [EAX] (mod=00, rm=0)
字节2
05 = imm8 = 5
有符号扩展: sign_ext(5, 8) = 5 (正数不变)
opr_src = {OPR_IMM, val=5}
长度
len = 1(opcode) + 1(ModR/M) + 1(imm8) = 3 字节
执行
operand_read([EAX]) → 从内存 [cpu.eax] 读值
alu_add(5, 旧值, 32) → 加法, 设标志位
operand_write([EAX]) → 写回内存
cpu.eip += 3
▼ 第 1 字节: opcode = instr_fetch(eip, 1) 256 个入口 所有指令解码的起点
▼ 0x00~0x3F — 双操作数算术/逻辑指令 (ADD/OR/ADC/SBB/AND/SUB/XOR/CMP) 64 个 opcode 每条指令占 3 个 opcode: r2rm_b, r2rm_v, rm2r_b, rm2r_v + i2a_b + i2a_v
▼ ADD 系列 (0x00~0x05)
0x00: ADD Eb,Gb → add_r2rm_b [2B]
读 ModR/M → reg=src(reg), rm=dest(r/m,mod); instr_execute: alu_add(src,dest,8)
0x01: ADD Ev,Gv → add_r2rm_v [2~7B]
同上, data_size=32/16; rm 可能是 SIB+disp32
0x02: ADD Gb,Eb → add_rm2r_b [2B]
读 ModR/M → reg=dest(reg), rm=src(r/m); instr_execute: alu_add(src,dest,8)
0x03: ADD Gv,Ev → add_rm2r_v [2~7B]
0x04: ADD AL,Ib → add_i2a_b [2B]
无 ModR/M！dest 固定 AL, src = 1B 立即数
0x05: ADD EAX,Iv → add_i2a_v [5B]
dest 固定 EAX, src = 4B 立即数
0x08~0D: OR (结构相同) ─ 0x10~15: ADC ─ 0x18~1D: SBB ─ 0x20~25: AND ─ 0x28~2D: SUB ─ 0x30~35: XOR ─ 0x38~3D: CMP
▼ 0x40~0x5F — 单字节寄存器指令 (INC/DEC/PUSH/POP r32) 32 个 opcode 无 ModR/M！寄存器号 = opcode & 7
0x40~47: inc_r_v [1B] — reg = opcode&7 → 读 reg → +1 → 写回, 保留 CF
0x48~4F: dec_r_v [1B] — 同上, -1
0x50~57: push_r_v [1B] — reg = opcode&7 → esp-=4 → [esp]=reg
0x58~5F: pop_r_v [1B] — reg = [esp] → esp+=4 → 写回 reg
▼ 0x66 — 操作数大小前缀 1 个 opcode
data_size_16() [1B]
全局 data_size 翻转为 16; 返回 1; 下一条指令用 16 位操作数
▼ 0x70~7F — 条件跳转 short (Jcc rel8) 16 个 opcode opcode 低 4 位 = 条件码, 后面 1 字节 = 有符号偏移
0x70: JO 0x71: JNO 0x72: JB 0x73: JNB 0x74: JE 0x75: JNE
0x76: JBE 0x77: JA 0x78: JS 0x79: JNS 0x7A: JP 0x7B: JNP
0x7C: JL 0x7D: JGE 0x7E: JLE 0x7F: JG
每条: len=2 → rel8 = instr_fetch(eip+1,1) → 如果 condition_XX → eip += 2+rel8
▼ 0x80~0x83 — Group 1: r/m + imm (需再读 ModR/M.reg 决定子操作) 4 × 8 = 32 条
解码步骤: opcode → group_1_XX() → 读 ModR/M → reg=子操作码 → group_1_XX_entry[reg]
0x80: group_1_b — ADD/OR/ADC/SBB/AND/SUB/XOR/CMP Eb,Ib [3B]
读 ModR/M.rm → r/m8 操作数; ModR/M.reg → 0=ADD 1=OR 2=ADC 3=SBB 4=AND 5=SUB 6=XOR 7=CMP; 接着 1B imm
0x81: group_1_v — 同上, Ev,Iv [6B] (32位imm)
0x83: group_1_bv — 同上, Ev,Ib [3B] (8位imm符号扩展)
▼ 0x88~0x8F — MOV (双操作数, ModR/M) 8 个 opcode
0x88: mov_r2rm_b — MOV Eb,Gb [2B]
0x89: mov_r2rm_v — MOV Ev,Gv [2~7B]
0x8A: mov_rm2r_b — MOV Gb,Eb [2B]
0x8B: mov_rm2r_v — MOV Gv,Ev [2~7B]
0x8C: MOV Ev,Sw (段寄存器) 0x8D: LEA Gv,M 0x8E: MOV Sw,Ew 0x8F: POP Ev
▼ 0x90~0x9F — 杂项单字节指令
0x90: NOP [1B] — 什么也不做, len=1
0x98: CBW/CWDE [1B] — AL→AX 或 AX→EAX 符号扩展
0x99: CLTD/CDQ [1B] — EAX→EDX:EAX 符号扩展
0x9C: PUSHF [1B] 0x9D: POPF 0x9E: SAHF
▼ 0xA0~0xBF — MOV(累加器+绝对地址), MOV(imm→reg), TEST, MOVS, STOS, LODS, SCAS
0xA0~A3: MOV moffs → AL/AX/EAX 及反向 [5B] (opcode + 4B addr)
0xA4~A7: MOVS (串移动) 0xA8~A9: TEST AL/AX/EAX, imm
0xB0~B7: mov_i2r_b — MOV r8, imm8 [2B] (reg=opcode&7)
0xB8~BF: mov_i2r_v — MOV r32, imm32 [5B] (reg=opcode&7)
▼ 0xC0~0xC7 — Group 2 (移位) + MOV imm→rm + RET
0xC0: group_2_b — SHL/SHR/SAR Eb,Ib [3B]
reg: 4=SHL 5=SHR 7=SAR; rm=r/m8; 接着1B移位次数
0xC1: group_2_v — 同上 Ev,Iv [3B]
0xC3: RET [1B] — eip=[esp]; esp+=4
0xC6~C7: mov_i2rm_b/v — MOV r/m, imm [3~8B]
▼ 0xD0~0xD3 — Group 2 移位 (移位1次 / 移位CL次)
0xD0: group_2_1b — SHL/SHR/SAR Eb,1 [2B]
0xD1: group_2_1v — 同上 Ev,1
0xD2: group_2_cb — SHL/SHR/SAR Eb,CL [2B]
0xD3: group_2_cv — 同上 Ev,CL
▼ 0xE8~0xEF — CALL / JMP / PUSH imm 无 ModR/M！
0xE8: CALL rel32 [5B]
rel32=instr_fetch(eip+1,4); esp-=4; [esp]=eip+5; eip+=5+rel32
0xE9: JMP rel32 [5B]
eip+=5+rel32
0xEB: JMP rel8 [2B]
eip+=2+rel8(有符号)
0x68: PUSH imm32 [5B]
0x6A: PUSH imm8 [2B] ※ 符号扩展到32位再压栈!
▼ 0x0F — 两字节 opcode 前缀 256 个二级入口 读 op2 = instr_fetch(eip+1, 1) → opcode_2_byte_entry[op2]
0x0F 0x44~0x4F: CMOVcc — 条件传送 [3~8B]
0x0F 0x80~0x8F: Jcc near — 条件跳转 rel32 [6B]
0x0F 0x90~0x9F: SETcc — 条件设字节 [3B]
0x0F 0xA3: BT — 位测试 [3B]
0x0F 0xB6~B7: MOVZX — 零扩展传送 [3B]
0x0F 0xBE~BF: MOVSX — 符号扩展传送 [3B]
0x0F 0x01: group_7 (LGDT/LIDT...)
▼ 0xF6~0xF7 — Group 3: TEST/NOT/NEG/MUL/IMUL/DIV/IDIV
0xF6: group_3_b — reg=0:TEST 2:NOT 3:NEG 4:MUL 5:IMUL 6:DIV 7:IDIV [2B]
0xF7: group_3_v — 同上, 32位 [2~7B]
▼ 0xFE~0xFF — Group 4 (INC/DEC r/m) + Group 5 (INC/DEC/CALL/JMP/PUSH r/m)
0xFE: group_4 — reg=0:INC Eb, reg=1:DEC Eb [2~7B]
0xFF: group_5 — reg=0:INC Ev, 1:DEC Ev, 2:CALL Ev, 4:JMP Ev, 6:PUSH Ev [2~7B]
▼ 0xF0~0xFD — 前缀 / 标志位指令 / 杂项
0xF8: CLC — CF=0 [1B]
0xF9: STC — CF=1 [1B]
0xFC: CLD — DF=0 [1B]
0xFD: STD — DF=1 [1B]
0xFA: CLI — IF=0 [1B]
0xFB: STI — IF=1 [1B]
0xF3: REP 前缀 [1B] 0xF4: HLT [1B]
0xCC: INT3 (BREAK_POINT) 0xCD: INT imm8 0xCF: IRET
▼ 0xD8~0xDF — x87 浮点指令 (Group x87) 8 × 8 = 64 条
0xD8~0xDF: 每个 opcode + ModR/M.reg → group_x87_XX_entry[reg]
FADD/FMUL/FSUB/FDIV/FLD/FST/FXCH/FCOM/FUCOM 等
▼ ModR/M 字节解析子树 用到 ModR/M 时必走此分支
Step 1: 读 ModR/M 字节 = instr_fetch(eip+1, 1) → 拆成 mod(2) reg(3) rm(3)
▼ Step 2: 根据 mod 分流
mod=00 无偏移: rm=4→SIB +disp32 | rm=5→disp32 | 其他→[寄存器]
mod=01 +disp8: rm=4→SIB+disp8 | 其他→[寄存器]+disp8(有符号)
mod=10 +disp32: rm=4→SIB+disp32 | 其他→[寄存器]+disp32
mod=11 寄存器: type=OPR_REG, addr=rm (0~7)
▼ Step 2b: rm=4 时读 SIB 字节
SIB = ss(2) index(3) base(3)
index≠4: idx = cpu.gpr[index]._32 * (1<<ss) | index=4: idx=0 (无变址)
base≠5: addr = cpu.gpr[base]._32 + idx | base=5且mod=0: addr = idx + disp32
最终: opr->addr = base + index*scale (+ disp)
最终返回: len = 1(ModR/M) + (SIB?1:0) + (disp? 1/4:0); 填充 opr->type/addr/sreg
▼ 执行阶段子树 译码完成后的指令执行
双操作数: instr_execute_2op() → operand_read(src) → ALU运算 → operand_write(dest)
单操作数: instr_execute_1op() → operand_read(src) → 运算 → operand_write(src)
条件指令: condition_XX → if(条件成立) 执行; else 跳过
▼ operand_read 分发
OPR_REG → opr->val = cpu.gpr[opr->addr]._32
OPR_MEM → opr->val = vaddr_read(opr->addr, opr->sreg, opr->data_size/8)
OPR_IMM → opr->val = vaddr_read(opr->addr, SREG_CS, opr->data_size/8)
